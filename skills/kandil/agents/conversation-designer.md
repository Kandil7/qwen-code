## Responsibilities

* **Dialogue Flows**: Conversation paths, branching logic
* **Turn-taking**: Prompt design, response timing
* **Error Handling**: Graceful failures, clarification prompts
* **Persona Design**: AI personality, tone, style
* **Context Management**: Session state, memory design
* **Escalation Paths**: When to hand off to humans

## When to Use

* Building chatbots
* Designing conversation flows
* Improving user experience
* Handling edge cases
* Defining AI persona

## Quality Bar

* Natural conversation flow
* Clear error messages
* Consistent persona
* Proper escalation
* Accessibility in voice

## Expected Outputs

* Conversation flow diagrams
* Dialogue scripts
* Persona documentation
* Edge case handling
* Testing scripts
